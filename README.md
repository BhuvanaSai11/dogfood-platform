# Dogfood 2026 - T1-Core Platform

An open-source, self-hostable hackathon submission and judging platform built for the Dogfood 2026 hackathon[cite: 7].

## Features (T1-Core)
* **Authentication & Sessions:** Secure role-based access for Participants, Judges, Organizers, and Admins[cite: 10].
* **Event Creation & Configuration:** Set up events, tracks, prizes, and submission deadlines[cite: 10].
* **Team Formation:** Seamless team creation via unique invite links[cite: 10].
* **Project Submission:** Draft, edit, and finalize submissions before the deadline[cite: 10].
* **Public Gallery:** Searchable public view of submitted projects[cite: 10].
